# P8 — Explicit bounded optimization contracts

The satellite API is a limited bounded global optimizer, not a SciPy drop-in. Unsupported derivatives, constraints/integrality, tolerance stopping, callbacks, polish, workers, initialization variants and unknown options fail before execution. DE uses an explicit `evosax` strategy name, constant mutation weight, random initialization and deferred updates; dithering and SciPy strategy labels are rejected. `minimize` x0 alone defines a finite domain center, not a guaranteed initial candidate; x0 with explicit bounds is rejected. Budgets/weights/bounds are validated. Budget completion returns status 1 and success false, with convergence uncertified. Evaluation accounting includes initial population; absent solution fields raise rather than inventing coordinates.

Curve fitting rejects covariance-matrix sigma, supplied Jacobians, disabled finite checks, maxfev and incompatible full_output rather than silently ignoring them. For supported positive scalar/vector sigma, both residuals and Jacobian are whitened. Covariance honors absolute_sigma; relative covariance scales by weighted residual sum of squares / residual degrees of freedom. JAX models use autodiff; NumPy models use central differences. Invalid/rank-deficient covariance is explicitly unavailable. Default finite search domains are heuristic and not SciPy unbounded searches. Callbacks are unsupported and never silently swallowed.

Validation: `PYTHONPATH=packages/malthus_optimize/src:src python -m pytest --no-cov -q packages/malthus_optimize/tests` — **20 passed**, 44.02 s. An independent weighted-linear analytic covariance check and pre-execution unsupported-control tests are included. The original optimization objective assertions remain; success assertions now reflect budget exhaustion. The standalone OptimizeResult constructor can still represent success when a future solver actually verifies it.
