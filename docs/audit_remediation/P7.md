# P7 — Regression identities, transformations and fit reporting

Pairing now requires unique non-null `(function, seed, D, P, G[, replicate_id])` identities and validated one-to-one joins. Counts/exclusions are recorded in DataFrame metadata. Dependent-variable transforms are raw objective, positive log, or explicitly declared log optimality gap with optimum/epsilon/orientation; no sample-dependent shift is invented. Model metadata records transform, identifiers, formula, rank and covariance. Rank-deficient/nonfinite designs fail explicitly. Selected covariance supports nonrobust/HC0/HC1/HC3 and explicitly supplied cluster groups, without claiming HC covariance solves dependence. Actual adjusted R², standard errors and t-values are exported; the analyzer no longer substitutes R² or empty uncertainty fields. Publication model/dependence choice remains a scientific predeclaration, not an automatic choice.
