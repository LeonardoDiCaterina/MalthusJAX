# P4 — Statistical validity and hypothesis-specific conclusions

P4 implements shared finite-sample validation, explicit inference availability, hypothesis-specific decisions, family-corrected exports, and policy-gated empirical inference. It does not select a publication equivalence margin or certify statistical power, and no new inferential/GPU/publication experiment was launched. Manuscript files and historical measurements remain unchanged.

## Validity and mathematical conventions

`MetricVector` requires finite one-dimensional numeric arrays. Paired samples must align; inferential entrypoints revalidate samples to prevent silently dropping subsequently mutated NaNs. Invalid structure/nonfinite input raises a clear error. Empty comparisons are rejected. One observation produces unavailable/insufficient inference, never equivalence. The declared comparison minimum must be at least two, with the existing default of ten retained as a mechanical gate rather than a power guarantee. Dataset builders preserve insufficient nonempty samples so the comparison can report `insufficient` explicitly, instead of preventing descriptive inspection.

Exact all-zero differences produce unavailable Wilcoxon/sign inference with a reason. Zero-variance paired differences produce unavailable paired t/TOST inference, including exact equality. This is a conservative software convention: observed equality is retained descriptively; it does not establish population equivalence. No p=1 or tiny favorable p-value is invented after an exception or degenerate variance. Finite nondegenerate tests delegate to SciPy. Shapiro-Wilk is not fabricated as p=1 for constants, and normality non-rejection is not treated as proof of assumptions or power. Undefined standardized effects return `None`; matched-pairs rank-biserial uses signed rank sums, rather than merely counting signs.

References for the underlying routines: [SciPy Wilcoxon](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.wilcoxon.html) and [SciPy one-sample t-test](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_1samp.html). The conventions for unavailable degenerate inference above are explicit project choices, not claims that every inferential framework must make the same choice.

## Decisions and compatibility

Statistical suite JSON uses **schema version 2**. `conclusion` is authoritative:

- Two-sided location tests: `difference_detected` / `difference_not_detected`.
- One-sided tests: improvement or deterioration detected/not detected according to the declared expected direction and metric orientation.
- TOST: `equivalent` / `equivalence_not_established`.
- Ineligible inference: `unavailable`, with `status`/`reason` distinguishing insufficient/unavailable results.

The first declared test is the primary difference test; the implementation does not fall back to a more favorable available test. TOST has its own decision basis. `TestResult.rejects_null()` is the explicit p<alpha operation. Legacy `passes()` now aliases rejection, not non-rejection. Likewise, compatibility `decision_pass` means the selected hypothesis is detected/established, never non-rejection parity. This is an intentional semantic change accompanied by the schema version and explicit conclusions. Legacy filenames such as `parity_summary.json` remain readable filenames, but console output now says paired difference analysis.

Raw decisions/conclusions remain separately available. Holm/BH correction determines selected suite decisions and JSON/Markdown/LaTeX conclusions. Planned unavailable hypotheses retain their place in the multiplicity family; missing inference cannot shrink the family after observing results. Duplicate family labels are rejected. Two raw equivalence p=.03 results adjust to .06 under Holm and both become `equivalence_not_established`. Nested JSON TOST `equivalent` uses the selected policy; `raw_equivalent` is labeled separately. Win counts honor the metric's lower/higher-is-better orientation. A significant deterioration cannot be labeled improvement.

## Paper generator and scientific decisions still required

The empirical generator now routes inference through shared statistical functions and defaults to **descriptive only**, including smoke runs and publication tiers. Legacy scalar p-value fields remain `None`; labeled raw/adjusted results live in `statistical_analysis`. The previous sample-derived relative TOST margin is not adopted. Compatibility helpers never manufacture p-values and require an explicit absolute margin for TOST.

Optional `--d5-statistical-policy PATH.json` loads and validates the policy before benchmark execution. The policy must declare a family name, sample-size rationale, alpha, minimum independent paired seeds, multiplicity policy, and all hypothesis labels/metrics. Each hypothesis declares its kind, primary test, estimand, metric orientation, sidedness, expected direction, and an absolute practical margin for equivalence. QD inference additionally requires matching P3 metric contracts. Producer metadata cannot conflict with the declared metric orientation. Repetitions are not independent seeds. These declarations make the analysis reviewable; the code does not certify that a rationale or sample count supplies sufficient power.

A policy has the following structure (placeholders are intentional and this is not an approved runnable publication policy):

```text
family: <predeclared family identifier>
sample_size_rationale: <power/precision rationale and independent sampling unit>
alpha: <chosen significance level>
minimum_pairs: <chosen independent seed count, at least two>
multiplicity: holm | fdr_bh | none
hypotheses:
  - label: <unique identifier>
    metric: best_fitness | coverage | qd_score
    kind: location_shift | equivalence
    primary_test: wilcoxon | paired_t | sign
    estimand: <mean_paired_difference | paired_signed_rank_location | paired_sign_probability>
    metric_orientation: lower_is_better | higher_is_better
    sidedness: two_sided | one_sided
    expected_direction: left_lt_right | left_gt_right
    margin: <positive absolute margin in reported objective units, required for equivalence>
```

TOST targets the mean paired difference. A Wilcoxon difference hypothesis declares signed-rank location, not an interchangeable mean estimand. Table captions use the policy's actual alpha; tables show every declared conclusion for a metric instead of selecting one favorable result. A missing policy displays descriptive-only text. Full manuscript claim/table alignment remains P10 work.
