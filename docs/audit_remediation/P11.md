# P11 — Distribution, assurance scope and operational documentation

The TensorNEAT transform is distributed under `malthusjax.core.fitness.composable.transforms`; the old checkout plugin re-exports it for compatibility. MAP-Elites imports the distributed implementation. GP/NEAT learning and NEAT visualization exports load lazily, so importing their core packages does not require optional sklearn/plotting libraries. Public export names remain available when their extras are installed.

The declared baseline is Python >=3.12 and JAX >=0.11,<0.13 (including backend extras), rather than promising untested old combinations. Existing package/docs workflows use Python 3.12. The Docker default uses Python 3.12 and copies LICENSE before package metadata resolution. **Docker execution is deferred to CI by the user's explicit choice; no local container pass is claimed.** A bare CUDA base override still needs a compatible Python runtime; the default CPU image is the CI target.

`scientific-remediation.yml` adds statistical/benchmarking, root scientific, prepared timing, island horizon, adapter metric/timing, isolated wheel, satellite and container checks. It measures and uploads scientific CPU coverage. These workflow definitions have been checked locally for YAML structure, but their hosted runs have not yet been observed. GPU gates remain separate. Maintained empirical/analysis and changed satellite sources pass Ruff's F checks without an unrelated formatting cleanup.

Coverage now includes the main genetic engine, statistics, scientific emitters and other previously omitted production paths. Only tests/cache and visualization/dashboard paths are omitted. The scientific selection (`tests/stats tests/benchmarking`) passed **230 tests**, nine warnings, 203.07 s and measured **6,326/12,958 statements (48.82%)**. This is scoped coverage, not full-suite coverage. The old 80% promise/threshold was removed; no new percentage target is asserted without a full baseline.
