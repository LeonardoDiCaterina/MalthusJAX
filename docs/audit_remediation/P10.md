# P10 — Publication evidence inventory and review-only rebuilding

`P10_evidence_inventory.json` inventories every current table and figure file with a content hash, applicable defects and disposition. Numerical-line candidates are anchored by manuscript file/line and content hash, without copying draft prose into this repository. Existing result summaries are listed as unmapped candidates: presence of a file is not a verified claim-to-source chain. QD/timing and island evidence affected by changed measurement/horizon contracts is flagged for rerunning. Other artifacts stay unavailable pending explicit source mapping, not automatically marked reproducible.

`python scripts/rebuild_publication.py --paper-root PAPER --output NEW_INVENTORY.json` performs the inventory. With `--left-manifest`, `--right-manifest`, `--policy`, and a fresh `--output` directory, it recomputes archive inference from immutable raw result snapshots using the shared P3/P4 contracts and exports deterministic `analysis.json` and `corrected_inference.tex`. It rejects unknown source/environment provenance, failed/missing-history inputs, unavailable inference and existing destinations. Dry-run validates and writes nothing. Output remains explicitly review-required; no manuscript paths are synchronized or overwritten. The older paper-side ingestion script remains a read-only legacy H2 checker; the new root entrypoint is the corrected raw-manifest-to-review-table path.

Validation: publication rebuild, P9 and result tests passed **11 tests**, 4.53 s before the final unavailable-value extension; the final combined P9/publication selection passed 51 tests. Fixtures verify byte-identical regeneration, read-only dry-run, preserved sources, rejected destination reuse and missing-provenance failure. The actual manuscript inventory was generated read-only; existing user manuscript changes were retained. Numerical paper claims have **not** been silently endorsed or replaced. Actual corrected paper results require reviewed source mappings, a task-specific inferential policy, and approved reruns where old measurements cannot be repaired by reanalysis. No publication-sized job was launched.
