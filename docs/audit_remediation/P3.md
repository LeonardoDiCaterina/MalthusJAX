# P3 — Shared metric semantics

The shared JAX archive reducer uses only finite occupied cells; -inf marks empty cells. NaN/+inf invalidate archive statistics. Empty archives have coverage zero and unavailable (NaN) best/mean/std/aggregate. Standard deviation is the population standard deviation (ddof=0), never sign-flipped. Native engines retain lower-is-better best/mean values; adapters report the requested objective orientation. Genetic adapter standard deviations likewise retain their sign.

`MetricSpec` is extended with units, orientation, and definition. Native and upstream QD adapters export the same version-1 metric contract, persisted by runner/results and empirical extraction. The compatibility `qd_score` is now explicitly the **sum of higher-is-better archive fitness over occupied cells with offset zero**, in objective-sum units. On minimization costs it is a negative sum of costs, not an absolute sum. No task-specific publication offset was selected. Custom upstream aggregate/offset definitions do not override this canonical reported aggregate. This is a behavior/schema change: legacy artifacts cannot silently acquire the new definition. The empirical comparison requires matching versioned contracts; otherwise it remains unavailable.
