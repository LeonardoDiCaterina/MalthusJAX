malthusjax.benchmarking.io module¶

Input/output helpers for experiment results.

This module handles reading and writing of JSON and CSV artifacts produced by benchmark runs. All writing is performed via atomic temp files to avoid corruption, and a convenience function builds per-seed directories for additional outputs.

malthusjax.benchmarking.io.write_summary_json(experiment_result, path)[source]¶

Persist an experiment summary to disk as JSON.

The target path is created if necessary, and the data is first written to a .json.tmp temporary file which is then atomically renamed. This guards against partial writes if the process is interrupted.

Parameters:

  • experiment_result (ExperimentResult)

  • path (Path | str)

Return type:

None

malthusjax.benchmarking.io.write_histories_csv(experiment_result, path)[source]¶

Dump the concatenated run histories to a CSV file with a seed column.

The headers are inferred from the union of keys present in the histories, and an empty file with just a header is produced if there are no rows.

Parameters:

  • experiment_result (ExperimentResult)

  • path (Path | str)

Return type:

None

malthusjax.benchmarking.io.ensure_seed_folder(output_dir, seed)[source]¶

Ensure a per-seed subdirectory exists and return its path.

The directory is named seed_XXXX where XXXX is the zero-padded seed value. This is convenient for organising artifacts generated by individual runs.

Parameters:

  • output_dir (Path | str)

  • seed (int)

Return type:

Path

malthusjax.benchmarking.io.write_experiment_artifacts(experiment_result, output_dir, write_csv=True, write_json=True)[source]¶

Emit all standard artifacts for an experiment and report their paths.

Depending on the flags the summary JSON and combined histories CSV are written. In all cases per-seed subdirectories are created and their locations are returned in the resulting mapping.

Parameters:

  • experiment_result (ExperimentResult)

  • output_dir (Path | str)

  • write_csv (bool)

  • write_json (bool)

Return type:

Dict[str, Path]
