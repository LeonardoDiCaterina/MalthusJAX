malthusjax.core.fitness package¶

Fitness module for MalthusJAX.

This module provides fitness evaluators using @struct.dataclass for efficient batch evaluation using JAX JIT compilation.

class malthusjax.core.fitness.BaseEvaluator(config, data)[source]¶

Bases: Generic[G, C, D]

JAX-native fitness evaluation interface with vmap composition.

Defines single-genome evaluate(genome) -> scalar, which vmaps into evaluate_population(population) -> population for Struct-of-Arrays (SoA) batching. Config (C) and data (D) are static (pytree_node=False) to remain constant across vmap lifting; only genomes are batched.

Type Parameters:

G: Genome type (e.g., RealGenome, BinaryGenome). C: Config type; typically pytree_node=False (static across vmap). D: Data type (e.g., training data, problem parameters); static.

Parameters:

  • config (C)

  • data (D)

config: C¶
data: D¶
evaluate(genome)[source]¶

Compute fitness for a single genome.

The provided genome (G) is an unbatched PyTree instance. Evaluators should extract necessary fields (e.g., .values) themselves according to the specific genome structure they expect.

The return value is a scalar (or a small vector for multiobjective cases) suitable for JIT‑compiled pipelines. Implementations may use self.config and self.data during evaluation.

Vectorized population evaluation via jax.vmap().

class malthusjax.core.fitness.KnapsackEvaluator(config, data=None)[source]¶

Bases: BaseEvaluator[BinaryGenome, KnapsackConfig, KnapsackData | None]

Knapsack problem fitness evaluator with linear constraint penalties.

Computes total value minus linear penalty for weight constraint violation. Penalty = excess_weight * penalty_factor (jax.lax.select, XLA-safe).

Data is stored as KnapsackData containing weights and values arrays. Use create_synthetic() to generate random problems or create_from_data() to load pre-computed weights/values (matching TSP interface).

Parameters:

  • config (KnapsackConfig)

  • data (KnapsackData | None)

config: KnapsackConfig¶
data: KnapsackData | None = None¶
evaluate(genome)[source]¶

Evaluate a binary genome representing item selection.

The returned value equals total item value minus a linear penalty for any capacity violation. This method is JAX‑safe and avoids Python control flow.

class malthusjax.core.fitness.BoxEvaluator(config, data=None)[source]¶

Bases: BaseEvaluator[RealGenome, BoxConfig, Any]

Box-constrained optimization with linear penalty for infeasibility.

Evaluates objective (distance or sphere) and adds linear penalty for constraint violations. Penalty uses jax.lax.select and jnp.maximum for XLA compatibility (no Python control flow during tracing).

Parameters:

  • config (BoxConfig)

  • data (Any)

config: BoxConfig¶
data: Any = None¶
evaluate(genome)[source]¶

Evaluate box-constrained problem on real genome.

Computes the selected objective and adds a linear penalty for any constraint violations (minimization convention). Lower values are better.

Note

Objective type is chosen by string; both branches are traced. An enum-driven dispatch is preferable for larger sets of objectives.

Parameters:

genome (RealGenome)

Return type:

Array | ndarray | bool | number | float | int
