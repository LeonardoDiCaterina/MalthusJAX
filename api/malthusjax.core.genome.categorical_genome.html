malthusjax.core.genome.categorical_genome module¶

Categorical genome representation for discrete search spaces.

Provides integer‑indexed sequence genomes along with permutation helpers and distance metrics. A matching population class offers batched operations and initialization.

is_permutation()[source]¶

Check if all categorical values are unique (valid permutation).

Uses jnp.unique(size=self.size, fill_value=-1) to pad uniques to expected length, then verifies absence of sentinel (-1). Returns JAX scalar boolean (JIT-safe; avoids Python control flow).
